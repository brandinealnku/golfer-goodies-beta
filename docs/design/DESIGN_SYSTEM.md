# Design System

CSS custom properties in `global.css` define deep pine and fairway brand colors, warm sand/white/stone surfaces, muted gold, semantic success/danger, text colors, spacing, radii, shadows, content width, a 48px touch target, z-index layers, and motion duration. System fonts avoid remote downloads.

Cards use image-led layouts and soft elevation. Status always includes text rather than color alone. Focus uses a three-pixel outline. Dialog actions remain sticky, mobile sheets stay below 90dvh, navigation accounts for safe areas, and the 320px breakpoint changes product and verification grids without shrinking text. Reduced-motion preference suppresses transitions and smooth behavior.
